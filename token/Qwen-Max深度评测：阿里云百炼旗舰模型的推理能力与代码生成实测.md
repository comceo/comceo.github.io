代码生成是检验大模型实用价值的核心场景。我们在阿里云百炼上调用Qwen-Max，测试了不同难度级别的编程任务。

### 测试1：算法实现（LeetCode Hard级别）

**Prompt：** "用Python实现一个LRU缓存，要求get和put操作时间复杂度均为O(1)，并附上详细注释和测试用例。"

**Qwen-Max生成代码：**

```python
class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = {}  # 存储 key -> node 映射
        # 使用双向链表维护访问顺序，头部为最近使用
        self.head = Node(0, 0)
        self.tail = Node(0, 0)
        self.head.next = self.tail
        self.tail.prev = self.head

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._remove(node)
        self._add(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self._remove(self.cache[key])
        node = Node(key, value)
        self.cache[key] = node
        self._add(node)
        if len(self.cache) > self.capacity:
            # 淘汰尾部节点（最久未使用）
            lru = self.tail.prev
            self._remove(lru)
            del self.cache[lru.key]

    def _remove(self, node):
        prev, nxt = node.prev, node.next
        prev.next, nxt.prev = nxt, prev

    def _add(self, node):
        # 添加到头部（最近使用）
        nxt = self.head.next
        self.head.next = node
        node.prev = self.head
        node.next = nxt
        nxt.prev = node

class Node:
    def __init__(self, key, value):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

# 测试用例
cache = LRUCache(2)
cache.put(1, 1)
cache.put(2, 2)
assert cache.get(1) == 1  # 返回1，1变为最近使用
cache.put(3, 3)           # 淘汰key 2
assert cache.get(2) == -1 # 返回-1
assert cache.get(3) == 3  # 返回3
```

**评测结论：** 代码结构规范，注释清晰，测试用例覆盖了边界场景。在百炼平台上**连续生成20次，代码可运行率100%**，无语法错误。
