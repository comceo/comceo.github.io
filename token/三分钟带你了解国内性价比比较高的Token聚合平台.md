**1. 免费额度大方**

新用户开通后，每个模型都送 100万 Token 的免费额度（有效期90天），几十个模型合计约7000万免费Token。对于个人开发者和原型测试来说，基本可以"零成本"跑通项目。

**2. Batch 调用半价**

支持 Batch 的模型，异步批量调用直接按实时价的 **50%** 计费，离线任务、数据处理等场景能省下一半的钱。

**3. 闲时折扣**

部分模型在夜间闲时（如 Qwen3.7 系列）有低至两折的折扣，定时任务放到夜间跑，成本可以再砍一大截。

**4. 上下文缓存折扣**

重复的长 Prompt、知识库文档走缓存命中，输入费用可降低60%–90%，这对 RAG 类应用是实实在在的省钱利器。

**5. 按量计费，无最低消费**

费用 = 输入Token×输入单价 + 输出Token×输出单价，用多少付多少。大多数轻量级应用一个月的模型开销只有几十到几百元。
