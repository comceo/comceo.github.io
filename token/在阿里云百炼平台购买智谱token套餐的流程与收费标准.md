# 在阿里云百炼平台购买智谱token套餐的流程与收费标准

## 一、先搞清楚：你要买的到底是什么

严格来说，"智普"通常指智谱 AI 的 GLM 系列模型（GLM-4、GLM-5 等）。在[阿里云百炼](https://www.aliyun.com/benefit/client/cross?userCode=6p8lcsnh)（Model Studio）平台上，GLM 作为**第三方模型**上架，与通义千问、DeepSeek、Kimi、MiniMax 等模型放在同一个平台里调用。也就是说，购买"智谱 token 套餐"的本质是：**在百炼平台上为 GLM 模型购买调用额度，或选择一种能覆盖 GLM 的计费套餐**。

需要先明确一点：百炼平台默认采用**按量后付费**，不会直接"赠送"token。如果你想提前锁定额度或降低成本，官方提供了三种可选形态：资源包（一次性购买固定 Token 量）、节省计划（承诺月消费换折扣）、Token Plan（一次性购买 credits 额度）。

## 二、收费标准详解

### 1. GLM 模型本身的计费规则

- **按输入、输出 Token 分别计价**：GLM 属于第三方文本生成模型，按实际调用的输入 Token 和输出 Token 扣费，支持 Batch 调用的模型，其输入输出单价按实时推理价格的 50% 计费（批量跑数据成本直接减半）。
- **免费额度**：每个模型提供 100 万 Token 免费额度，有效期为开通百炼之日起 90 天，用于测试基本够用。
- **地域限制**：第三方模型（DeepSeek、Kimi、GLM、MiniMax）仅支持华北2（北京）地域，使用 GLM 时 API Key 和 Base URL 必须对应北京地域。
- **具体单价**：GLM 各版本（如 glm-4、glm-5 系列）的输入/输出单价会随版本更新调整，请以百炼控制台"模型广场"中该模型的定价页实时显示为准——这是下单前最后确认价格的唯一可靠口径。

### 2. 三种套餐形态怎么选

| 维度  | 资源包 | 节省计划 | Token Plan |
| --- | --- | --- | --- |
| 计费模式 | 一次性购买固定 Token 量 | 承诺月消费换阶梯折扣 | 一次性购买 credits 额度 |
| 模型覆盖 | 仅适用单个特定模型 | 覆盖绝大部分阿里直供模型 | 仅支持部分模型 |
| 适用场景 | 用量小或集中调用 GLM | 长期稳定、用量可预期 | 团队协作共享额度 |

官方选型建议：长期稳定使用选节省计划；用量较小或集中在 GLM 单一模型选资源包；需要团队共享额度选 Token Plan。

几个关键细节：

- **资源包**：购买后立即生效抵扣，优先消耗免费额度，免费额度用完才开始抵扣资源包。国内站的大语言模型推理节省计划档位从 20 元到 50 万元共 11 档，有效期从 1 个月到 1 年不等。
- **节省计划**：如果你高频调用 GLM，重点关注 **AI 通用型节省计划**——GLM 的阿里直供版本属于其 C 类抵扣范围，承诺每月消费可换取阶梯折扣（长期高频使用最低可至约 5.3 折）；但需注意三方直供版本不支持抵扣，模型是否有阿里直供版以控制台实际展示为准。
- **Token Plan**：订阅制，用"Credits"作为统一计量单位，开通后可在通义千问、GLM 等多个模型间自由切换，无需为每个模型单独购买额度包，支持席位分配、用量统计、多租户隔离，且团队版数据不用于模型训练。目前公开的三档参考价为：标准版坐席 ¥198/月（25,000 Credits）、高级版坐席 ¥698/月（100,000 Credits）、尊享版坐席 ¥1,398/月（250,000 Credits），具体价格以下单页为准。

**第 3 步：选择套餐并下单。**

- 只调 GLM、用量小 → 在控制台购买对应模型**资源包**；
- 用量稳定且大 → 购买 **AI 通用型节省计划**（注意选支持 GLM 直供版的档位）；

**第 4 步：获取 API Key。** 支付完成后进入百炼控制台 → 密钥管理 → 创建新的 API Key。

**第 5 步：配置到开发工具。** 以 OpenAI 兼容接口为例，北京地域 Base URL 为 `https://dashscope.aliyuncs.com/compatible-mode/v1`，填入 API Key 后将 model 设为 `glm-4` 或 `glm-5` 等具体型号即可调用。Cursor、Claude Code、Cline、Cherry Studio 等主流工具均支持此接入方式。
