## 三、创建 API Key

调用百炼 API 前，必须先创建 API Key（即 AccessKey 或业务空间 API Key）。

### 方式一：创建业务空间 API Key（推荐）

1. 在百炼控制台左侧菜单，点击「API Key 管理」
2. 点击「创建 API Key」
3. 为 Key 命名（如 `my-first-key`），选择有效期
4. **立即复制并妥善保存**——这是唯一一次能看到完整 Key 的机会

### 方式二：使用阿里云 AccessKey

如果你需要更细粒度的权限控制，也可以使用阿里云 RAM 用户的 AccessKey ID 和 AccessKey Secret，但配置相对复杂，初学者建议先用方式一。

## 五、API 调用实战（Python 示例）

下面是用 Python 调用阿里云百炼 API 的完整代码，以 **通义千问** 为例。

### 5.1 安装依赖

```bash
pip install dashscope
```

`dashscope` 是阿里云官方提供的 Python SDK，封装了百炼平台的模型调用接口。

### 5.2 单轮对话示例

```python
import dashscope
from dashscope import Generation

# 设置你的 API Key
dashscope.api_key = "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"  # 替换为你的 API Key

# 调用通义千问模型
response = Generation.call(
    model="qwen-turbo",  # 模型名称：qwen-turbo / qwen-plus / qwen-max
    messages=[
        {"role": "system", "content": "你是一个乐于助人的智能助手。"},
        {"role": "user", "content": "请介绍一下阿里云百炼平台的主要功能。"}
    ],
    result_format="message",  # 返回格式
    max_tokens=1500,          # 最大生成 Token 数
    temperature=0.7           # 随机性（0~1，越大越有创意）
)

# 处理响应
if response.status_code == 200:
    print("模型回复：")
    print(response.output.choices[0]["message"]["content"])
else:
    print(f"调用失败：{response.code} - {response.message}")
```

### 5.3 多轮对话示例（带上下文记忆）

```python
import dashscope
from dashscope import Generation

dashscope.api_key = "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

# 维护对话历史
messages = [
    {"role": "system", "content": "你是一个专业的编程助手。"}
]

# 第一轮对话
messages.append({"role": "user", "content": "Python 中列表和元组有什么区别？"})

response = Generation.call(
    model="qwen-plus",
    messages=messages,
    result_format="message"
)

reply = response.output.choices[0]["message"]["content"]
print("AI:", reply)

# 把模型的回复加入历史
messages.append({"role": "assistant", "content": reply})

# 第二轮对话（带上下文）
messages.append({"role": "user", "content": "那字典呢？和它们相比有什么特点？"})

response = Generation.call(
    model="qwen-plus",
    messages=messages,
    result_format="message"
)

print("AI:", response.output.choices[0]["message"]["content"])
```

### 5.4 流式输出示例（打字机效果）

如果希望在网页或终端实现「逐字输出」的效果，可以使用流式调用：

```python
import dashscope
from dashscope import Generation

dashscope.api_key = "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

messages = [
    {"role": "user", "content": "写一首关于人工智能的短诗。"}
]

# 启用流式输出
responses = Generation.call(
    model="qwen-turbo",
    messages=messages,
    result_format="message",
    stream=True,  # 关键参数：启用流式
    incremental_output=True
)

print("AI: ", end="", flush=True)
for response in responses:
    if response.status_code == 200:
        content = response.output.choices[0]["message"]["content"]
        print(content, end="", flush=True)
    else:
        print(f"\n流式输出异常：{response.code}")
print()
```

## 六、cURL 调用方式（不用安装 SDK）

如果你不想用 Python，也可以直接用 HTTP 请求调用：

```bash
curl https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation \
  -H "Authorization: Bearer sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-turbo",
    "input":{
        "messages":[
            {"role": "system", "content": "你是一个 helpful 的助手。"},

        ]
    },
    "parameters": {
        "result_format": "message",
        "max_tokens": 800
    }
  }'
```

## 八、费用与额度说明

阿里云百炼采用 **按量付费** 模式，根据实际调用的 Token 数量计费：

- **输入 Token**：你发送给模型的文本对应的 Token 数
- **输出 Token**：模型回复你的文本对应的 Token 数

计费公式：**总费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价**

不同模型的单价不同，`qwen-turbo` 最便宜，`qwen-max` 最贵。具体价格以控制台「计费管理」页面为准。

## 九、常见问题 FAQ

**Q1：API Key 泄露了怎么办？**

> 立即到「API Key 管理」页面删除旧 Key，重新创建新的 Key，并更新到代码中。

**Q2：调用时提示 "QuotaExceeded"？**

> 说明你的免费额度已用完或付费额度不足。前往控制台「额度管理」充值或购买资源包。

**Q3：如何查看我的 API 调用量和费用？**

> 在百炼控制台 → 「用量统计」可以查看按天/按月的调用量、Token 消耗和费用明细。

**Q4：支持哪些编程语言？**

> 除了 Python SDK（dashscope），还支持 Java、Go、Node.js、PHP 等，也可以直接用 HTTP API 调用，语言不限。

**Q5：百炼和通义千问官网有什么区别？**

> 通义千问官网是面向 C 端用户的聊天界面；百炼是面向开发者的 B 端平台，提供 API、模型微调、应用搭建等企业级能力。
