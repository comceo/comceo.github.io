## 二、WorkBuddy 核心功能详解

### 1. 自然语言操控，一句话派活

WorkBuddy 的核心交互方式极其简单：用自然语言描述你的需求即可。无论是"帮我整理桌面上的发票并生成汇总表"，还是"根据这份竞品数据做一份 PPT 分析报告"，只需一句话，AI 就会自动理解意图并开始执行。支持语音输入（小程序端）和图片输入，真正实现了"零门槛"办公提效。

### 2. 多模态内容生成

WorkBuddy 能够自动生成多种格式的办公成果，包括：

- **文档**：Markdown、Word 格式
- **表格**：Excel、CSV 数据处理
- **演示文稿**：PPT 自动生成
- **可视化图表**：数据图表、网页、前端代码

你只需下达指令，它即可在本地电脑上完成从内容创作到格式排版的全流程。

### 3. 自主任务规划与交付

这是 WorkBuddy 区别于普通 AI 工具的最大亮点。它具备"听得懂、有脑子、能干活"的特性：接收到需求后，AI 会自动进行需求拆解、步骤规划与执行，全程无需人工干预，直接交付可用结果。

### 4. 本地文件深度操作

经用户授权后，WorkBuddy 可以读取本地文件夹，执行批量文件处理、代码构建、文件合并与转换等实操任务。支持 Office（Word/Excel/PPT）、PDF、图片等常见格式的读写操作，真正打通 AI 与本地工作流的"最后一公里"。

### 5. 多 Agent 并行协作

面对复杂项目，WorkBuddy 支持多个智能体（Agent）同时协作处理不同子任务，大幅缩短整体完成时间。你可以在侧边栏随时切换和管理多个并行任务。

### 6. Claw 远程控制

通过手机端主流 IM 工具（微信、企业微信、QQ、飞书、钉钉），你可以随时随地远程下发指令，电脑端的 WorkBuddy 会自动执行并回传结果。这意味着即使不在工位，也能让"AI 同事"帮你干活。

### 7. 小程序双模式

WorkBuddy 提供微信小程序入口，支持两种运行模式：

- **云上模式**：无需电脑，云端沙箱开箱即用，适合轻量任务
- **本机模式**：远程操控桌面端 WorkBuddy，适合需要本地文件操作的重度任务

### 8. 记忆功能

WorkBuddy 内置记忆系统，能够记住你的偏好、上下文和背景信息，并在后续对话中自动调用。即使你关闭了对话，下次打开时它依然记得你之前告诉它的信息，告别"每次重新介绍自己"的尴尬。

### 9. MCP & Skills 扩展生态

WorkBuddy 内置主流 MCP Server 和 Skills 技能包，支持通过技能市场安装扩展（如生图、学习等插件），也支持自定义模型配置，灵活拓展工具能力边界。企业用户还可通过 API/MCP 插件接入内部系统（订单、CRM 等）。

### 10. 多模型自由切换

WorkBuddy 支持混元、DeepSeek、GLM、Kimi、MiniMax 等多个大模型，用户可根据任务类型自由切换。国际版更内置 Claude、GPT-5、Gemini 等国际顶级模型。

### 11. 企业级安全管控

WorkBuddy 提供文件夹级精细授权访问，高危操作自动拦截并请求用户确认，任务在隔离环境中执行，全面保障数据安全。

## 五、安装与注册教程

### Windows 安装步骤

1. 访问官网
2. 双击下载好的 `WorkBuddySetup.exe` 安装包
3. 按安装向导点击"下一步"完成安装（建议安装到非系统盘）
4. 安装完成后桌面会生成 WorkBuddy 快捷方式
5. 首次打开使用腾讯云或 CodeBuddy 账号登录，没有账号可点击注册（支持手机号或邮箱）

### macOS 安装步骤

1. 下载对应芯片版本：Apple Silicon（M 系列）选 ARM64，Intel 芯片选 x64
2. 双击 `.dmg` 文件，将 WorkBuddy 图标拖入 Applications 文件夹
3. 若提示"无法打开"，前往系统设置 → 隐私与安全性 → 允许
4. 登录账号并授权文件访问权限

### 注册方式

- **国内版**：支持微信扫码、手机号、邮箱注册，新用户赠送 5,000 Credits 额度
- **国际版**：支持 Google 账号或 GitHub 账号 OAuth 授权登录，新用户赠送免费试用积分
