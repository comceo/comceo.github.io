## 三、手把手实操：从零开始配置你的AI周报助手

### 第一步：初始化配置（一次性，约15分钟）

首次使用时，需要"教会"AI你的工作背景。打开WorkBuddy，按以下模板发送：

```
帮我记录一下我的工作背景：

【基本信息】
- 姓名：张三
- 职位：产品经理
- 行业：互联网

【负责项目】
- 项目A名称（进行中）
- 项目B名称（已上线）

【汇报要求】
- 汇报频率：每周五下午5点前
- 汇报对象：直属上级
- 汇报格式：
  1. 本周工作（按项目分类）
  2. 存在问题
  3. 下周计划
- 领导关注点：项目进度、数据指标、风险控制
```

收到"√已记录你的工作背景"即表示配置成功。

---

### 第二步：每日记录习惯（每天多次，每次10秒）

**无需专门打开文档写日志**，只需在完成工作时像聊天一样对WorkBuddy说一句：

| 场景  | 标准话术 |

WorkBuddy会回复"√已记录到 [日期].md"，表示记录成功。

## 五、避坑指南

| 坑   | 解决方案 |
| --- | --- |
| 需求描述太模糊 | 把具体工作内容列清楚，输出质量直接取决于输入信息量 |
| 没指定格式 | 提前说明"分三部分""用表格""控制在500字以内" |
| 忘记用本地文件 | 直接让它"读取本周的日报文件，汇总成周报"，比手动复述更准确 |
| 数据口径不统一 | 各部门先对齐字段再上传，避免AI汇总出来的数对不上 |
| 让AI编数字 | 所有数字必须来自原表，偏离超范围的一律标"需核实" |
