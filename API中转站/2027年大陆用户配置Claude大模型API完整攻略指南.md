## 四、接入开发工具实战

### 4.1 接入Claude Code（命令行编程工具）

Claude Code是Anthropic官方推出的命令行AI编程助手，通过环境变量即可指向第三方平台：

```bash
# 设置环境变量（Windows PowerShell）
$env:ANTHROPIC_BASE_URL = "平台提供的接口地址"
$env:ANTHROPIC_AUTH_TOKEN = "sk-你的密钥"

# 启动
claude
```

macOS/Linux用户将环境变量写入 `~/.bashrc` 或 `~/.zshrc` 即可永久生效。

### 4.2 接入Python代码

使用官方SDK，只需改两个参数：

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="sk-你的密钥",
    base_url="平台提供的接口地址"
)

message = client.messages.create(
    model="claude-sonnet-latest",
    max_tokens=1024,
    messages=[{"role": "user", "content": "你好，介绍一下你自己"}]
)
print(message.content[0].text)
```

## 五、常见问题排查

- **401错误**：密钥填错或末尾多了空格，重新复制粘贴
- **404错误**：Base URL写错，注意路径末尾是否需要加 `/v1`
- **429错误**：触发速率限制，降低请求频率或联系平台提升额度
- **余额不足**：部分平台有最低调用额度要求，充值后重试
- **模型名不存在**：第三方平台的模型名称可能与官方略有差异，以平台文档为准
